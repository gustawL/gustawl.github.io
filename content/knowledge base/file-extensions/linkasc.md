In the security/cryptography context, it's' an **OpenPGP “ASCII-armored”** file:<br> binary key/signature/message data encoded as plain text so it can be copied into emails, web pages, etc. <br><br>
This file format also be used for unrelated things (example: ActionScript server scripts), <br>so **the extension alone is not proof** of what it contains. <br>
> *reference:*
> [file.org - "... known uses of the ASC file extension"](https://file.org/extension/asc)
