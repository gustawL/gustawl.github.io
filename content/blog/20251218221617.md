## Project/case workflow

“Question → analysis → final product.”

1. A project starts with two things: a dataset and a question. The combination of questions and data is the core of the project.
- We can start from a dataset → find a question we want to answer.
- We can also start from a question, and find the data related to it.

 Regardless of which point we start from, the next step is analysis.

1. Try to answer the question using the data, writing everything down along the way.
2. Write a blog about what you did or what you didn’t manage to do. Keep the code in a public space, together with documentation.
