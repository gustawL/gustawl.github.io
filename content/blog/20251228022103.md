## Ready solution
```powershell
Get-Content (Get-PSReadLineOption).HistorySavePath
```

or open in notepad
```powershell
notepad (Get-PSReadLineOption).HistorySavePath
```
## Problem
I wanted to check in the history which commands I used before I carelessly closed PowerShell.  
I found that just typing `History` or `Get-History` doesn't return anything. <br> Meanwhile, I noticed that PowerShell remembers and autocompletes commands I used before closing PowerShell. PSReadLine writes command history to a file. Lucky me.
