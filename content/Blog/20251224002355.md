## Emerge specific kernel version
Assuming (for example) You want version 6.18.1:
``` sh
sudo emerge sys-kernel/gentoo-sources:6.18.1
```

## How do I find package version number?
Use equery:
``` sh
equery list -po sys-kernel/gentoo-sources
```
